# Netflix-Content-Data-Analysis

## Project Overview

This project analyzes Netflix content data to uncover insights about movies and TV shows available on the platform. The analysis focuses on understanding content distribution, popular genres, country contributions, content trends over time, and other key metrics.

The project combines Excel, SQL, Python, and Power BI to perform data cleaning, exploration, analysis, and visualization.

## Tools & Technologies Used

- Excel – Initial data exploration and basic cleaning
- SQL – Data transformation and analytical queries
- Python – Data processing and analysis
- Power BI – Interactive dashboard and data visualization


## Data Cleaning (Excel & Python)

- Removed missing or inconsistent values
- Standardized columns and formats

## Data Analysis (SQL)

- Movie vs TV Show distribution
- Country-wise content production
- Top genres on Netflix
- Content release trends by year
- Most frequent directors
- Content distribution by rating
- Longest movies and average durations

## Data Visualization (Power BI)

- Interactive dashboards
- Content trends visualization
- Country vs genre analysis
- Genre and rating distribution

## Key Insights

- Movies dominate Netflix compared to TV shows.
- Certain countries contribute the majority of Netflix content.
- Drama and International genres appear most frequently.
- Content production increased significantly after 2015.
- Some directors have multiple titles available on Netflix.

## Conclusion

This project demonstrates how different data analysis tools can be combined to extract meaningful insights from entertainment industry data. By using SQL for analysis, Python for processing, Excel for preparation, and Power BI for visualization, the project highlights trends and patterns in Netflix content distribution.
